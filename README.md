# htmlreader

- `index.html`: chat simples com o Claude via Puter.
- **[`clipador/`](clipador/)**: plataforma de cortes automáticos de lives. Cola o canal (YouTube, Twitch ou Kick), ele grava em blocos de 10 min, detecta os lances (volume × movimento × fala), corta em pé com legenda, dá nota e posta sozinho no TikTok, Reels e Shorts. Veja o [README do Clipador](clipador/README.md).
